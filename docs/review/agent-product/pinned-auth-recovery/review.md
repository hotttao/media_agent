# 旧 Session 模型认证恢复

## 问题与结论

用户看到“模型登录缺失或已失效”，实际发送的是验收 Workspace 的 Session 1（dcfa20e7-3a81-4af2-8bb4-39b050f64607），固定配置版本1。数据库确认该历史版本没有 API Key 或个人模型连接；Workspace 当前版本3明确绑定有效的“本机 Codex”。恢复只解除暂停，因此继续恢复旧 Session 不能取得当前配置中的认证。另一个旧验收 Workspace 未绑定正式连接，其历史 Session 也不能隐式借用它。

## 变更

聊天区在固定版本落后时展示会话/Workspace 版本，以及“使用当前配置新建会话”。新建成功切换新会话，旧会话继续保留原配置及历史；不会因元数据版本落后禁止旧会话发送。创建中及流式执行期间禁用新入口，失败保留旧会话并显示已有错误反馈。认证报错明确针对当前会话，说明恢复会沿用原配置。

UI旅程、spec和plan同步；服务端认证、连接引用与Session固定规则保持原有已确认语义。本次没有修改、重新导入或替换“本机 Codex”原始认证文件。
