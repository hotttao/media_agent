1. 复用现有 Asset Kind、Material、Product 查询接口，在列表组件持有筛选/搜索/页码状态；Material 类型使用常驻展开的多选表单并由服务端按集合过滤。
2. 扩充 i18next 中英文资源，将默认语言设为中文，并在独立站点 Shell/登录页提供切换入口。
3. 翻译本次触达的列表和入口文案，验证类型筛选、分页参数、语言持久化及前端类型检查。
4. 扩展 `media_ai_migrate` 读取动作素材与姿势映射；在 Material 页面展示动作内容与视频，存储上传按真实媒体类型校验；旧姿势 ID 暂存待兼容关系能力落地。
