# Workflow UI v1.2 开发计划

范围以 [spec](../../spec/ui_design/workflow-v1.2.md) 和已确认 [旅程](../../ddd/ui_design/workflow-v1.2-flow.md) 为准。每批可独立验证，未完成批次不能宣称整体 UI 完工。

## 1. Slot 与视觉基础

- [x] 保留注册、Header Portal、实例生命周期；来源改为实例状态，验证切换 App 保留视图。
- [x] 实现暖浅色 Token、自带字体、白色 standalone 导航及统一 App 子导航。
- [x] 隔离 plugin 样式及 Radix portal，验证 standalone/plugin 双构建与实际宿主 fixture。

## 2. 列表与信息层级

- [x] 工作流、模板、我的任务：真实分页/搜索/状态、异常与空态、无假统计；模板状态/任务名称筛选明确当前页范围。
- [x] 素材导航/类型多选及分页、详情字段与图片布局对齐设计。

## 3. 定义工作台

- [x] Workflow 全幅画布、按需节点配置、折叠设置、添加模板、删除影响提示。
- [x] Template 槽位/提示词/映射编辑、版本草稿/发布状态、能力查询降级。
- [x] 校验/保存/发布/注册就绪交互；权限命令已接入，完整授权查询另列缺口。

第二批进度：工作流已实现按需配置、删除影响确认、改名维护引用、实例内草稿恢复、创建 Workspace 选择与冻结 Template 版本读取。模板已纠正 Provider 引用、只读派生身份、槽位/调用映射维护与响应式分组。校验返回及保存回执已适配，发布中轮询已接入。完整模板映射交互、共享与创建/发布业务写入验收尚未完成，因此本节不整体勾选完成。

第三批进度：编辑器左侧工具箱、已发布模板选择浮层、元数据弹窗、Header Portal 工具栏、全高画布和按需输入配置；详情改为全幅画布，元信息与执行中记录按需打开，归档确认并等待成功。模板选择读取确切版本契约，校验结果绑定草稿指纹。此批不等于模板、任务/审批、素材和共享页全部完成，完整业务闭环仍待后续批次验收。

第四批进度：模板调用映射提供三种结构化表达式、有序列表移动及嵌套编辑；重建默认映射确认，本地槽位/引用检查，模板草稿按 instance 保留。模板工具栏进入 Header Portal，元信息放设置，详情结构化显示正文/槽位/参数；历史读取错误不替换为当前数据。已接原生 owner 发布接口，保存与共享操作分离。真实只读浏览器编辑回归通过，创建/版本保存/发布业务写入以及部门授权仍待闭环验收，不提前勾选完成。

## 4. 执行闭环

第七批：把执行图恢复为详情主区域，节点 Inspector 按点击打开，输入审计进入弹窗；旧版本真实 StepRun 列表降级。组件验证未开始节点、轮询不开启 Inspector、终态不审批、跨 App 选择恢复与 Escape；真实借用执行只读回归，不执行历史数据修改或性能优化。

第七批进度：执行画布和窄容器 Inspector 已实现，4 项页状态回归通过；未确认审批意图不依赖已卸载的 Hook 错误，恢复后可同键重放。输入快照预览适配冻结引用前缀，存储仍执行企业检查。真实画布/结果/关闭/窄屏/输入图片回归通过（1.6m），没有写入借用执行；完整提交/审批/恢复写入验收继续独立记录，不扩大为引擎调度开发。

- [x] 商品兼容定义选择/宿主导航端口/预填保留与不自动执行，standalone 和旧 plugin 降级验证。

- [x] 结构化运行输入、稳定提交意图、真实注册状态与输入校验。
- [ ] 执行拓扑/版本降级、结果预览、当前轮审批及异步回执。
- [ ] 失败继续、反馈再生成、整次输入覆盖重跑、历史补缺继续。
- [ ] 权限/共享 UI 使用真实授权事实，查询缺口明确记录。

## 5. 验收

- [ ] 列表查询性能优化：用户要求推迟至 UI 全部完成后统一处理；保留已有四路并发验证，不继续修改查询契约。

- [ ] 中英、键盘、桌面/窄 Slot、媒体失败状态。
- [ ] 单元/组件/真实浏览器 E2E；测试遵循 contributing，不修改借用历史样本。
- [x] typecheck、dep-check、双构建、plugin 宿主 fixture 隔离及实例恢复验收；实际 media_platform 接入不由 fixture 替代。
- [x] 更新设计→实现→测试矩阵，列出剩余后端只读支持与降级项。

第五批进度：执行详情采用真实节点导航、候选/历史产物预览、输入摘要和窄屏可读的输入快照；审批使用数组位置与稳定意图，异步回执等待处理，不冒充完成。提交/补缺/输入覆盖重跑使用真实 Workspace 和类型化资源，旧版本契约缺失禁止用新版本替代。恢复原任务加载后才初始化表单，取消回到原执行。素材扩展字段结构化编辑，虚拟形象服务端搜索分页，生成产物优先解析 object_path；纯文本不显示媒体加载失败。共享接可查询部门及原授权命令。具体复杂支持缺口汇总于 [查询缺口](../../review/ui_design/workflow-v1.2-query-gaps.md)，尚不整体勾选执行闭环与验收。

第六批进度：真实模板创建/版本保存/发布和 Workflow 创建/校验/保存/Conductor 注册闭环通过；修正 SlotBinding HTTP 数字枚举，新建定义只选择同企业模板。商品到运行表单通过可选 Navigation Port 投递一次性实例意图，清空选择后跨 App 往返不会重新填入，不自动提交。真实表单验证注册就绪、Workspace 和资源选择、实际图片加载。审批补充同图再生成的精确回执解锁及接受后不重复提交测试；历史已接受媒体使用存储 content_type 展示无扩展名视频。未执行新的 Job/审批端到端写入，不将组件与只读回归冒充完整执行验收。
