# Agent 资源管理与配置交互

## 入口与边界

企业资源库是受保护的企业级管理页 `/library/:organizationId?`，通过 Menubar 进入，不占用 Workspace Slot。企业选择来自 Auth 当前有效成员列表；Prompt、Skill、MCP 分别显示真实可见目录。Workspace Settings 继续作为既有单实例 App，承载 Agent 配置与 Workspace MCP 绑定，不另建 Shell 或绕过 Slot 状态。

资源库和 Settings 沿用已确认 Penpot Agent 项目及 Workflow 的暖浅背景、白色面板、深色主按钮与黄色重点。资源列表与内容编辑器并列，窄屏通过返回列表切换；表单和历史使用可滚动区域，主要操作始终可达。界面称系统默认指引，不暴露 Platform Prompt 模板装配细节。

## 资源旅程

Prompt：当前企业列表 → 新建默认私有 → 编辑正文/名称 → 查看固定历史 → 明确回滚为新版本。owner 可编辑授权及归档，editor 编辑内容，viewer 读取；没有权限时不显示可提交的修改动作，服务端拒绝仍作为最终事实。

Skill：选择在线创建、ZIP/tar.gz 上传或 Git 导入 → 文件树编辑草稿 → 校验并明确发布 → 发布历史浏览/下载。Git 凭据为写入式密码字段，留空保留、明确清除才能删除；不放入 URL、localStorage 或日志。手动同步和发布均提示尚未改变任何 Agent 的固定选择。二进制只下载，不以文本覆盖。删除文件、丢弃草稿、回滚和归档均展示具体目标后确认。

资源授权：私有、指定部门、企业可见三选一；部门 viewer/editor 在同一企业范围选择，owner 保存时带当前 expected_version。当前 Auth 仅提供所属部门列表，是否开放企业有效部门名称查询正在单独确认；在确认前不扩大读取范围。

MCP 目录：企业 admin 登记/编辑本企业外部 HTTP/SSE MCP，平台 admin 可维护平台定义；普通成员只查看授权列表。认证类型为无、Bearer、API Key、OAuth，目录不填写秘密。Workspace Settings 创建绑定并配置写入式凭据、启停与固定定义版本。OAuth 使用 Auth 弹窗授权，校验 postMessage origin 与来源窗口，完成后重新请求连接状态；断开需要确认，不把回调消息当作已连接事实。

## 明确确认 Agent 配置

Prompt 不设置、直接填写、引用资源库三种方式互斥；库选择包括固定版本。Skill 只能选发布版本，MCP 选择绑定的固定版本。保存前展示来源与版本变化，用户明确确认后提交 Control expected_version/idempotency_key。保存成功刷新权威 Workspace 与选择信息，不自动修改当前会话。

已有会话保持原配置并继续使用；界面可提示当前选择已有更新，并提供新建会话入口，不能因仅元数据版本变化阻止发送。Agent 类型发生变化时，新执行使用新会话，原历史保留。保存失败保留输入并展示可重试/重读操作，409 要求重新加载后确认，不能自动覆盖。

## 状态与保密

组织、列表、详情、历史和文件请求均有加载、空态、失败与重试。企业切换会清除选中项、草稿和秘密字段，取消/忽略旧请求结果。未授权、归档、已停用和未发布是不同状态，不以空列表替代错误。

资源事实、版本、ACL、凭据是否配置归服务端；表单、未保存文件、列表筛选和秘密仅在当前组件内存。公开浏览器接口不读取内部代理凭据端口。窗口关闭和成功保存后清空秘密，网络失败不打印请求体。前端操作可见性不替代 Workspace manage 或服务端资源授权。

## 验证

组件验证企业/部门选择、只读权限、互斥 Prompt 来源、固定版本选择、秘密清空与冲突。浏览器验证资源创建编辑、Skill 导入/发布、MCP 配置、明确更新以及旧会话继续使用。后端真实 HTTP/数据库检查与浏览器替身场景分别记录，正式 Docker/模型使用另行验收。
