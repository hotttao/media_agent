# 客户端 Worker 执行上下文

客户端执行已领取的媒体能力任务，保留生成与交付事实；调度与执行资格由工作流上下文决定。

## 业务术语词典

**Task（执行任务）**：网关交给客户端的一次不透明 Dispatch 及其 Attempt、能力和输入。

**Capability（执行能力）**：由稳定名称与版本共同标识的媒体处理契约。

**Result（待交付结果）**：某次 Attempt 已确定、等待网关确认的输出或失败事实。

**Checkpoint（生成检查点）**：同次 Attempt 已保存的生成意图、生成引用及确切产物事实。

**Generation Request（生成请求）**：包含稳定 Key、已渲染提示词、媒体类别、顺序参考图和显式参数的生成意图。

**Reference（生成引用）**：生成器返回的、不透明的单次生成身份。

**Artifact（生成产物）**：由确切 ID 标识的生成结果媒体。

**Execution Admission（执行准入）**：领取任务前对专用生成实例容量和就绪状态的确认。

**Browser Image Generation（浏览器成图）**：在用户已登录的浏览器中提交提示词与有序参考图，取得图片产物的生成方式。

**Conversation Binding（会话绑定）**：一次生成与确切远程会话之间不可变的关联，恢复只能观察该会话。

**Media Management Batch（媒体管理批次）**：同一调用主体及组织范围下，针对同一种媒体管理操作提交的一组独立请求；每项独立授权和返回结果，批次不构成跨对象事务。
