# GPT 生成流程变更

## 2026-10-26 · 独立编排

用户要求不与 Studio 共用 generate。新增 gpt_generate，通过公共 Executor/ExecutionRecovery 接入 execute；持久化边界、浏览器绑定、人工与恢复行为由 GPT 自己定义。旧 generate 正名为 doubao_generate。

## 2026-10-27 · 空闲准入与进程中断验证

空队列准入改为只读探测，拒绝有草稿或生成中的页面；就绪结果缓存最多 5 秒，生成相关调用使缓存失效。首次页面导航仅由显式浏览器准备命令触发。增加独立 Python 进程在持久化发送意图后退出的恢复验证，并将 bridge 行为测试纳入 Go 常规测试入口。

实际 Chrome 验证发现新版编辑器不再位于 form、对话不再位于 main，新增局部 DOM 适配。Send 确认后记录确认回执及摘要探测，延长身份传播等待；绑定失败仍不重发。恢复改用只读查询/下载函数，保留页面供前后身份核验，避免上游 recover 命令关闭页面；按 file_id 去重同图的消息引用，多个不同产物保留人工检查。
