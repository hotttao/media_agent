# Workflow 画布内运行向导 Spec

## 核心旅程

新建页提供的 Template 必须归属当前企业；旧无企业模板即使可读取也不代表可绑定到新企业 Workflow。保留历史 Workflow 查看/运行，不自动修改原模板或授权。

1. 工作流详情点击运行，仍位于当前 Workflow App。画布保持可见，首个需要外部输入的节点高亮，右侧展开运行准备面板。
2. 每个节点按 slot_bindings 中 workflow_input 引用显示入口字段。例如 model_image 选择商品与形象，style_image 选择姿势，first_frame 选择场景，video 选择动作。
3. 字段采用可搜索的媒体卡片，不再使用仅显示名字的原生下拉。商品用主图、Virtual IP 优先全身图，图片素材展示图片；视频可预览，纯文本动作展示文字，无图片时给真实空态而非加载失败。
4. 本节点必填输入全部有效后才能下一步；可选输入可留空。可以返回修改，保留其他节点选择。同名共享入口只选一次；修改后消费者都使用同一值。不问 const 或未来 step_output。
5. 完成输入后显示复核：Workflow 固定版本、企业、合法 Workspace、已选资源与审批策略。点击开始执行才提交；不存在逐节点先提交/提前生成。
6. 已存在的自包含 JobInput 构建、稳定意图键及未知响应重放继续复用。提交中禁止改选；失败留在原画布保留选择。同意图不重复建 Job。
7. 成功在同一 Workflow App 打开该执行画布，不途经任务列表。取消返回定义画布。

## 数据与实现边界

- 拓扑/入口契约来自 Workflow 详情及其发布版本；非法环、重复节点、缺少绑定/入口声明不能推断可提交。
- 资源只来自已授权 Organization/Scope/Asset Kind；媒体短签不持久化。结果不替代后端的最新权限和可达性校验。
- 现有 Product/VIP 有服务端名称查询；Material/Generated Asset 没有名称查询。本轮沿现有兼容资源接口分页读取清单，再按名称/文字本地搜索，不把首 200 条当全量，不伪造新的后端搜索参数。签发/预览只针对当前显示的一页卡片，避免把全部图片同时加载。
- 用户当前可见素材量有限；超大素材库的服务端关键词搜索是后续明确接口扩展，不在本轮改 DDD 或增加代理调度能力。
- 商品详情的“可用工作流”是输入兼容性查询。目标详情再次确认 run 动作和 registered 回执，已归档商品不能发起；没有 Navigation Port 时只读提示。
- Workflow List 是已授权只读轻量摘要，不含 allowed_actions/my_permission；不能把缺字段当无权而过滤全部候选。企业归属明确的候选按 Scope/PRODUCT 契约筛选；无企业历史摘要仅允许 created_by 匹配当前用户，选中后由完整 Detail 再核验权限及发布回执，绝不据摘要直接执行。
- 旧全局/未绑定企业定义仅在后端明确授予 owner/run 且 Scope 一致时可作为当前用户的兼容定义；不因此扩大跨企业资源权限。
- 不修改 Submit/Retry/Resume/审批/Conductor 语义，不增加 Worker Token，不触碰已迁入历史执行。Resume/Rerun 原冻结版本表单保留。

## 异常与布局

加载、无兼容资源、搜索无结果、查询失败、媒体不可读、失去执行权限和版本变化分别显示。无图片可正常选择有效文本资源。需要未声明的入口时禁用运行，不退回 JSON 输入。

宽 Slot：画布 + 停靠的输入面板；窄 Slot：画布上的应用局部覆盖面板，可收起后定位节点，关闭不丢草稿，不覆盖宿主全屏/导航。中文默认、中英文文案同时维护，键盘可选择卡片和执行前后步骤。

## 验收

纯函数覆盖无输入节点跳过、共享入口去重、分支顺序、环/未知引用；组件覆盖搜索、图片、必填、回退、复核和只提交一次；浏览器经真实网关完成工作流内准备及商品预填，取消后断言没有 Submit/Resume 请求。

## 设置与取消契约

新建空草稿的最终输出控件禁用并说明先添加节点；设置提供“确定，返回画布”，仅关闭设置，不保存或发布。已有节点可选择最终输出，设置关闭及再次打开保留草稿。

取消运行不提交 Job：由 Workflow 发起时回到原 Workflow；由 Product 发起时使用可选 Navigation Port `openProduct`，Materials 消费企业及商品 ID 意图后定位 Product 详情，不使用上次 Tab。旧宿主没有此端口时返回原 Workflow；Resume/Rerun 仍返回源 Job。
