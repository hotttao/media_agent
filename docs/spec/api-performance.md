# API 性能优化

范围：现有认证、控制、素材、模板、工作流、任务及存储读接口。先提交已有功能，再测量和优化；不调整 UI、不执行历史任务、不增加业务功能。

保持响应字段、分页、顺序、权限隔离、撤销检查、历史对象校验及 Conductor 状态权威。不得用长期授权缓存或省略引擎查询换速度。

验收：只读网关 Token/Cookie 基线对比，隔离数据库查询预算测试，存储并发/失败/取消测试，JWT 错误 issuer 不访问 JWKS 且伪造签名仍拒绝，相关单元测试与架构检查。

初步热点：商品页图片 SQL N+1；生成素材逐条两次 HEAD + 签名；错误 issuer 引发多余 JWKS；任务列表实时投影需进一步测量。三次顺序样本仅作为诊断中位数，不代表生产 P95 或并发吞吐。
