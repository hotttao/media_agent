# Media Workflow UI 设计规范(v1.1)

> 来源:Penpot 文件「工作流 UI · v1.1」(画板 ux-01 ~ ux-15)。
> 本文件是前端实现的唯一视觉依据;设计原则参考 taste-skill(反模板、单一强调色、克制卡片)。

## 1. 设计基调

- **暖浅色编辑风**:奶油白对角渐变底 + 白色卡片 + 炭黑重点块 + 鲜黄点缀。
- **用户视角优先**:状态一眼可辨(草稿/已发布/已归档、运行中/待确认)、失败语义明确、操作入口就近。
- **禁止**:纯黑 #000000、AI 紫渐变、大面积低对比灰字、无意义弹窗(详情一律子页/抽屉)。

## 3. 字体

- **Plus Jakarta Sans**(Penpot 内已启用);weight 层级:`700` 页面大标题/KPI 数字、`600` 卡片标题/激活页签、`500` 行名/徽章、`400` 正文。
- 中文回退系统字体;字号阶梯:42(登录 hero)/ 30(详情页名)/ 26(列表页题)/ 15(页头)/ 13(正文)/ 11(辅助)/ 10(眉标)。
- 正文行高 1.6;辅助信息必须是 tertiary 色以外的真实语义,禁止大面积低对比。

| 元素 | 圆角 | 阴影 |
|---|---|---|

## 5. 组件规范

### 顶部导航(所有页)
白色悬浮条(`mx-6 mt-4 rounded-[18px] h-[54px]`):黄块 logo + 产品名 + 一级页签(素材库/工作流)+ 搜索 + 头像。**不用深色导航**。

### 子导航(工作流域)
导航下 `h-11` 行:工作流 / 模板 / 任务,激活项炭黑 600 字重 + **黄色 2px 下划线**。

### 深色重点块(层次来源,克制使用)
- 列表页**左侧筛选面板**(状态/输入类型/工作流过滤,含激活行黄块);
- KPI 卡中**一张**黄色卡(其余白卡);
- 执行详情的**视频预览区**;
- 运行页的**串联逻辑说明卡**。
深色:`#1F1E1B`,内部分层 `#2B2A26` / `#383630`,文字 `#F7F4EA` / `#A29E90`。

### 徽章
胶囊,`文案长度×字号 + 16` 宽;状态徽章 = 功能色底 14% + 深色同系文字;类型徽章 = 领域类型色。

### 表格行(列表页)
白底行卡(`rounded-xl` + 发丝线),左侧 3px 类型条,行内:名称 600 + 版本徽章 + 状态徽章 + scope + 摘要 + 时间。

### 详情一律子页
Product/Asset/Job 详情 = 独立子页(`DetailPage` 布局),**不是弹窗**;子页结构:返回行 → 图片/标题区 → Sections(受众/详情/行动/电商/元数据)→ 归属引用(如 Product 归属工作流)→ 使用记录 → 审计 → 管理(删除)。

## 7. DDD 对齐红线(实现时必须遵守)

1. 画布连线只表示 `SlotBinding.source=step_output`;workflow_input/const 是节点参数。
2. `output_step_key` 是唯一汇点,节点标「最终输出」。
3. media_type 枚举 = `{IMAGE, TEXT, VIDEO}`;kind = asset_kind 注册名,不是媒体格式。
4. 工作流串联 = 输入检索按 asset_kind 匹配;无显式连线。
5. 状态徽章文案用领域枚举原文(draft/published/archived/need_confirm…)。
